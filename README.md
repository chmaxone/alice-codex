# Алиса и Codex

Приватный навык Яндекс Диалогов для запуска Codex CLI на Raspberry Pi. Один фоновый процесс Codex App Server держит отдельный диалог для каждого аккаунта. Если в уже открытом диалоге ответ готов за 3,3 секунды, навык сразу его озвучивает. Иначе Codex продолжает работу в фоне. Скажите «Ответ» или повторите тот же вопрос в течение 45 секунд после успешного выполнения, чтобы услышать результат.

## Запуск

Нужны Node.js 20 или новее и авторизованный Codex CLI в PATH. Сборка компилирует TypeScript в JavaScript для Node.js.

```sh
npm ci
npm run build
npm start
```

Перед запуском создайте файл `webhook-token` из 64 шестнадцатеричных символов в рабочем каталоге. Для нового развёртывания его можно создать командой `(umask 077; openssl rand -hex 32 > webhook-token)`. Сервер слушает `127.0.0.1:8796`. HTTPS-прокси должен передавать POST на `/alice-codex/<токен>` с исходным путём.

На Raspberry Pi скопируйте оба файла `dist/*.mjs` в `~/alice-codex/` и перезапустите службу `systemctl --user restart alice-codex`. Файл с токеном хранится рядом с ними и сохраняется при обновлении.
