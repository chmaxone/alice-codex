# Алиса и Codex

Приватный навык Яндекс Диалогов для запуска Codex CLI на Raspberry Pi. Вебхук сразу подтверждает запрос, а Codex готовит ответ в фоне. Чтобы услышать результат, скажите «Ответ». Если повторить тот же вопрос в течение 45 секунд после успешного выполнения, навык зачитает сохранённый результат.

## Запуск

Нужны Node.js 20 или новее и авторизованный Codex CLI в PATH. Сборка компилирует TypeScript в JavaScript для Node.js.

```sh
npm ci
npm run build
npm start
```

Перед запуском создайте файл `webhook-token` из 64 шестнадцатеричных символов в рабочем каталоге. Для нового развёртывания его можно создать командой `(umask 077; openssl rand -hex 32 > webhook-token)`. Сервер слушает `127.0.0.1:8796`. HTTPS-прокси должен передавать POST на `/alice-codex/<токен>` с исходным путём.

На Raspberry Pi служба `alice-codex.service` запускает собранный `dist/server.mjs`, установленный как `~/alice-codex/server.mjs`. Файл с токеном хранится рядом с ним и сохраняется при обновлении.
